# 🛍️ Sales Analysis – Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on sales data to understand customer shopping patterns and identify useful insights from different demographic and geographical factors.

The analysis focuses on questions such as:

* Which **states** have the highest shopping activity?
* How does shopping behavior differ between **male and female customers**?
* Which **product categories** are purchased more frequently?
* What type of products are preferred by customers from different states?
* How do **gender, state, and product category** relate to shopping behavior?

The project uses Python-based data analysis and visualization techniques to transform raw sales data into meaningful insights.

---

## 🎯 Objectives

The main objectives of this project are:

1. Clean and prepare the sales dataset for analysis.
2. Perform exploratory data analysis on customer and sales information.
3. Analyze shopping patterns across different states.
4. Compare purchasing behavior between male and female customers.
5. Identify popular product categories.
6. Visualize relationships between demographic and shopping variables.
7. Extract meaningful insights that can support data-driven business decisions.

## 🔍 Analysis Performed

### 1. Data Cleaning

The dataset was examined and cleaned before analysis.

Steps included:

* Checking dataset structure
* Identifying missing values
* Handling unnecessary columns
* Checking data types
* Removing duplicate/unwanted records where required
* Preparing categorical and numerical columns for analysis

### 2. State-wise Analysis

The project analyzes shopping activity across different states to identify geographical patterns.

This helps answer:

> **Which states have higher shopping activity?**

Visualizations are used to compare shopping behavior across states.

### 3. Gender-wise Analysis

Customer purchasing behavior is analyzed based on gender.

The analysis helps answer:

> **How does shopping behavior differ between male and female customers?**

Gender-wise comparisons are performed across shopping-related variables and product categories.

### 4. Product Category Analysis

The project identifies which product categories are more commonly purchased.

This helps answer:

> **What type of products are customers purchasing?**

### 5. State + Gender + Category Analysis

One of the key parts of the project is combining multiple dimensions to understand customer behavior.

For example:

**State → Gender → Product Category**

This allows the analysis to identify patterns such as:

> Customers from a particular state, grouped by gender, show different preferences for specific product categories.

This multi-dimensional analysis provides more detailed insights than looking at each variable separately.
